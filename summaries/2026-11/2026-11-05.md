# FPP Updates — November 5, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

3 commits, all from Daniel Kulp, focused on memory use when playing FSEQ sequences and on making failed updates safer. All landed on the morning of November 5.

## Stability fixes

- **FSEQ playback uses far less memory.** Compressed sequences no longer set aside a large, unused working area when they are only being played back, and each background reader now takes a much smaller slice of memory. This mainly helps 32-bit players (older Raspberry Pi setups) running many FSEQ effects at once, which could run out of memory and crash. If a sequence reader still can't start, opening that sequence now fails cleanly, as a missing file does, and the next attempt tries again.

## System and UI

- **A failed update no longer leaves FPP half-updated.** If an update stopped partway because of a conflict with local changes, FPP could be left in a broken state that blocked every later update until fixed by hand. The update now backs out and reports the failure, leaving your install as it was.
