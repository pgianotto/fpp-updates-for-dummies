# FPP Updates — November 13, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

31 commits, 29 from community contributor darylc and 2 from jessica12ryan. Almost all bug fixes rather than new features: playlist, backup, and file-save correctness, a batch of OS-upgrade reliability fixes, output-hardware quirks, and two security fixes. Two of the jessica12ryan fixes were originally made on November 10 and 12 but only merged into master in this batch.

## Security

- **A stored XSS vulnerability in System settings is fixed: SSH `authorized_keys` content is now escaped before being shown**, so a crafted entry could no longer run script code in your browser (jessica12ryan).
- **The About page's git log display now escapes commit text**, closing a similar script-injection risk (darylc).

## Playback and playlists

- **Inserting a new item into a playlist no longer overwrites a different playlist that FPP couldn't read** (darylc).
- **A playlist item that's missing now shows its name as plain text in the playlist editor**, instead of being interpreted as something that could run (darylc).
- **Playlist and script save requests that don't actually include the expected data are now rejected**, instead of silently failing or leaving a bad save behind (darylc).
- **Renaming a playlist now keeps the original if the rename fails, and Rename/Copy no longer silently overwrites another playlist with the same name** (darylc).
- **Display Testing now plays a sequence from the beginning when Start Time is left empty**, instead of doing nothing (darylc).
- **The stop, previous, and next buttons now tell you when the player failed to respond**, instead of looking like nothing happened (darylc).

## Scheduler

- **Extend Schedule now refuses an answer that isn't a valid number** (darylc).
- **Calendar View no longer lists a late-evening scheduled command twice, and its hover text now matches what's shown** (darylc).
- **The warning that a holiday rename didn't reach the schedule can now actually be read**, instead of showing garbled text (darylc).

## Backup and restore

- **A backup's comment is now shown as plain text in the backup lists**, rather than being rendered as HTML (darylc).
- **A restore from the backup list that fails now says so**, instead of failing silently (darylc).
- **Restoring just the "Miscellaneous" backup area now only touches its own files**, instead of also affecting unrelated settings (darylc).

## Outputs and hardware

- **A PCF8574 output's "Hysteresis Off" level is now read back correctly** after being saved (darylc).
- **An MQTT output's topic and payload are no longer cut off at an apostrophe** (darylc).
- **A GPIO-595 output now keeps its pin assignments through a save**, instead of losing them (darylc).
- **Pixel Overlay Models that failed to load can now be saved over**, instead of getting stuck unusable (darylc).

## Files and uploads

- **Uploading a new sequence file over one that's currently playing no longer leaves a half-written leftover file behind** (darylc).
- **A sequence upload now only replaces the original file once the entire upload has arrived**, closing a window where a partial file could get used (darylc).
- **Rename and Copy for files now refuse to overwrite a file that already exists**, instead of silently clobbering it (darylc).

## System and network

- **The storage device check no longer warns about, or writes, an empty device during settings load** (jessica12ryan).
- **Updating a network interface at the "Basic" level no longer loses its DHCP server, route metric, or IP-forwarding settings** (darylc).
- **No DHCP proxy rule is created for an interface that already gets its address via DHCP** (darylc).
- **Browsers reporting an older-style time zone name now get correct map coordinates, and the Time Zone dropdown keeps its selected value**, instead of resetting (darylc).

## Stability fixes (OS upgrades)

- **A failed OS copy during an upgrade no longer reboots into a half-written system** (darylc).
- **The image-size lookup used during an upgrade can no longer hang the whole process** (darylc).
- **SSH access no longer depends on completing a first boot after an OS upgrade** (darylc).
- **The first-boot "expand" marker, and (on BeagleBone Black) the FAT partition, are no longer accidentally copied into the new OS** (darylc).
- **Downgrading to an older image now keeps the correct partition stage headers**, avoiding an inconsistent downgrade (darylc).

## Upgrade note

- If you have scripts, plugins, or external tools calling FPP's playlist or script save APIs, malformed requests (missing playlist/script data) are now explicitly rejected rather than silently accepted — check that your integration handles the new error response.
- File Rename/Copy now refuse to overwrite an existing file; if you relied on the old silent-overwrite behavior, delete the target first.
