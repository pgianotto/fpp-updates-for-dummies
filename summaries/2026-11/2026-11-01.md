# FPP Updates — November 1, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

13 commits, eleven from Daniel Kulp and two from darylc, mostly fixes to MultiSync, video playback, random media playlist entries and a few smaller bugs. One commit landed in the early hours of November 1 and the rest during the day.

## Playback and playlists

- **Random media entries in the same playlist no longer all pick the same file.** If a playlist had several "random" media entries, they could end up choosing the identical file; each one now picks on its own.
- The Prefix field on a random media entry can now be shown and edited in the playlist editor.
- The playlist editor's row label no longer runs into its details when the browser text size is large (darylc).

## Video and audio

- **H.265 video is now decoded in software** instead of using the Pi's built-in hardware decoder, which was causing problems with these files.
- The "Hardware Decoding" setting now properly keeps video off the hardware decoders when you turn it off.
- The audio diagnostics check now records from the default input source, so the test reflects what the system actually uses.

## MultiSync and updates

- **Remotes ignore stale sync messages.** A remote FPP no longer reacts to a sync message that arrives after the sequence or media it refers to has already stopped, which could cause a stray restart or jump on the remote.
- A remote whose video keeps falling out of step now stops repeatedly skipping around trying to catch up.

## Outputs and hardware

- The pixel limit applied to unlicensed outputs now counts a string's blank (null) pixels correctly, so the limit is measured the way you'd expect.

## Security

- The DHCP client table on the proxies page now respects the "Hide External URLs" setting.

## Stability fixes

- Backups made through the API no longer delete the backup they just created when cleaning up old ones.
- FPP now cancels any web requests still in progress when it shuts down, so a stray background thread is no longer left behind.

## System and UI

- Developer documentation: fixed out-of-date references in the plugin development guide (darylc).

## Upgrade note

- If you use H.265 video, expect it to play through software decoding now; very high-resolution files may use more CPU on lower-powered boards.
