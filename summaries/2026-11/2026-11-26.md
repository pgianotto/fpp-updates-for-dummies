# FPP Updates — November 26, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

2 commits from November 26, both from Daniel Kulp, fixing a video-timing issue on pixel overlay models and a stale-data bug when editing LED panel matrices.

## Video and audio

- Fixed a bug where playing video to a pixel overlay model (like a video panel matrix) could make the whole show — picture, sound, and the lights following them — fall further and further behind the clock whenever a box couldn't decode and scale the file fast enough, sometimes slipping several seconds over the course of a song. The video pipeline now converts and scales each frame more efficiently, and simply drops frames that have fallen too far behind rather than trying to catch up, so everything else stays on time. When a file drops a lot of frames, FPP now logs a note at the end of the track saying the box can't keep up and suggesting a lower resolution or frame rate.

## System and UI

- Fixed a bug on the Channel Outputs page where adding or removing an LED panel matrix could show an "unsaved changes" state right after you'd just saved. The page had been re-reading the config file back from disk before the save had actually finished writing it, so it sometimes compared against stale data. It now trusts what it just saved instead of re-fetching it.
