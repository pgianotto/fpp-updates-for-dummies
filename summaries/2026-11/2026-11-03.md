# FPP Updates — November 3, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

9 commits, five from Daniel Kulp, two from OnlineDynamic and two from darylc, mostly AES67 audio-over-network improvements plus a few small web interface and settings fixes. All landed on November 3, several in the early morning.

## Outputs and hardware

- **AES67 audio now plays nicely beside a sound card.** A new AES67GraphClockPriority setting lets the audio system run at 48 kHz alongside a regular sound card, and an output group that only sends AES67 now runs the audio system at 48 kHz on its own.
- **Better clock drift correction on capes with a fixed clock.** The automatic drift correction can now reach the true speed of these capes' clocks.

## Stability fixes

- **Fewer false audio-gap warnings.** When audio had to be converted to a different sample rate, FPP no longer reported a gap in the source on every buffer. Where such warnings still occur, they are summarized after the first 20 instead of flooding the log (OnlineDynamic).
- **AES67 time sync no longer jumps the system clock.** When the network clock service runs with software timestamps, it can no longer step the computer's own clock (OnlineDynamic).
- **Settings reloads are safer.** A reload no longer overwrites a setting that is still being saved (darylc).

## System and UI

- The Network help page no longer talks about the removed Restart DNS button (darylc).
- The plugin settings page no longer prints the plugin's config file path on screen (darylc).
