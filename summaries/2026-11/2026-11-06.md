# FPP Updates — November 6, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

11 commits, mostly from Daniel Kulp plus contributions from Starfield3 and OnlineDynamic (and one automatic dependency bump). The main themes were Falcon V5 receiver timing, nested playlists, PocketBeagle 2 hardware, and macOS fixes. All landed on November 6.

## Playback and playlists

- **Stopping an inserted playlist no longer restarts the one it interrupted.** If you inserted a playlist into a running one and then hard-stopped the inserted playlist, FPP would wrongly resume the original. It now stays stopped.

## Outputs and hardware

- **Falcon V5 receiver communication is more efficient and more reliable.** FPP now asks each group of receivers for information once per round instead of repeatedly (Starfield3). Related fixes stop send-only V4 receivers from being counted as if they used the heavier V5 traffic, stop the frame-time estimate from counting its queries twice, and keep a V5 receiver's "rest" frame in place if a frame is declined. Expect steadier timing on BeagleBone shift-string setups with mixed V4/V5 receivers.
- **PocketBeagle 2: the BOOT button can now trigger things.** You can use it as a GPIO input to start playlists, run commands and so on.
- **Cape EEPROM upgrades match your hardware.** When FPP offers a firmware/EEPROM upgrade for a cape, the versions offered now fit the hardware you actually have installed.

## Stability fixes

- **Audio default ranking is set after an update.** Boxes that were updated now get the default ranking for the "Simple" audio output on first boot, so audio output selection behaves as on a fresh install (OnlineDynamic).
- **A stray network packet no longer freezes the bridge on macOS.**
- **Logging scripts now work on macOS's older bash.** The `op` and daemon logging scripts previously failed there.

## System and UI

- **Behind-the-scenes web component update** (follow-redirects 1.16.2, via Dependabot). No visible change.
