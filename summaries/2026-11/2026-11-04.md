# FPP Updates — November 4, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

14 commits, nine from darylc, three from Daniel Kulp and two from OnlineDynamic, mostly small fixes to playlists, commands and audio, plus a new safeguard for plugins that modify FPP's own files. All landed on November 4, many in the early morning.

## Playback and playlists

- **Playlist checks name a missing video output.** If a playlist uses a video output the system doesn't have, the validation now says which one (darylc).
- **Editing a playlist entry is more reliable.** Changing an entry no longer saves an empty drop-down choice as the text "null", and picking a file always closes the File Chooser (darylc).
- **FSEQ effects play at their own speed.** An FSEQ effect now goes out at the frame time stored in the sequence itself (darylc).

## Commands

- **Command drop-downs keep their choice.** A command's drop-down list now keeps its value and its position (darylc).
- **Empty preset list is reported correctly.** With no presets defined, the list of preset names is now empty rather than "null", which avoids errors in scripts and the web interface (darylc).

## Video and audio

- **Boot-time PipeWire default audio output now sticks**, rather than being changed afterward (OnlineDynamic).
- **USB sound cards with "HDMI" in the name are no longer mistaken for the board's HDMI port** (OnlineDynamic).
- **Remote control of the second media slot works with PipeWire.** The control API can now reach media and volume for slot 1 (darylc).
- **The video output list works on systems without graphics device info**, so it no longer fails there (darylc).

## Outputs and hardware

- **BeagleBone PRU startup fix.** On AM335x BeagleBone capes, FPP no longer wipes the PRU's memory before starting it, which could break output startup.

## System and UI

- **File Manager buttons that need a selection start disabled** until you pick a file.
- **The `fpp` command-line help is accurate.** It now says which options have been removed and lists `-r` as working (darylc).

## Upgrade note

- **Plugins that edit FPP's own files are now detected.** During an update, FPP sets such edits aside instead of silently keeping or overwriting them. If you use a plugin that patches FPP files, check it after your next update.
