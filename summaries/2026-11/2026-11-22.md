# FPP Updates — November 22, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

3 commits: two Playlist Editor interface fixes from darylc, and a fix from Daniel Kulp for a rare freeze bug that could lock up an entire show.

## Playback and playlists

- Fixed a timing bug that could freeze FPP completely — not just one playlist, but the main control loop, the web UI, and the status page all at once. It only showed up in an unusual sequence: starting a playlist that's nested inside another one (via Insert Playlist) right as a new start and a new "Insert Playlist Immediate" landed in the same narrow window. Two parts of the system ended up each waiting on a lock the other one held, and nothing could move until the show was restarted. Playback now always takes those locks in the same order, so that standoff can't happen.

## System and UI

- In the Playlist Editor, editing an FPP Command's "Set Variable" action never showed the Expression, Amount, or Minimum/Maximum fields when you picked "Set To" — only a plain value field appeared, even though those options existed. The same problem hid the color options for the Overlay Model Effect's Text effect: choosing "Palette" as the Color Mode never revealed the palette colors or Color Speed setting. Both now show up correctly, matching how they've always worked in the separate Command Editor. (darylc)
- Clicking "+ Add Command" under an If command's "Then Run" or "Otherwise Run" branch, while working directly in the Playlist Editor, did nothing — it silently failed with a JavaScript error. That's fixed, so commands can now be added inside an If branch the same way they can anywhere else. As part of the fix, doing this inside an If no longer wipes out a Recurring Task's Result Variable/Filter settings. (darylc)
