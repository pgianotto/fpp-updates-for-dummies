# FPP Updates — November 8, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

19 commits: 17 from darylc and 2 from Daniel Kulp. The main themes were a sweep to make web pages safer with unusual names, scheduler and recurring-task save checks, and WiFi/network fixes. Ten of the commits were pushed late on the evening of November 7, and several others landed in the early hours of November 8.

## Security

- **Names with special characters are handled safely across the web pages.** Schedule, playlist, variable, preset, command and file names (and their arguments) are now escaped wherever pages display them or build links from them, so odd characters can't break a page or sneak in unwanted content (darylc).
- **Web API paths are decoded once, not twice**, closing a gap where specially crafted requests could be misread (darylc).

## Scheduler and recurring tasks

- **Scheduler Save now tells you if FPP doesn't confirm the reload**, instead of silently looking successful (darylc).
- **A disabled playlist no longer hides one that will actually play on the schedule calendar** (darylc).
- **Recurring Tasks Save is safer.** It refuses intervals that are too short, reports a failed reload, and won't overwrite a file it couldn't read (darylc).

## Outputs and hardware

- **Pi screen output (DPI) and a virtual matrix on the same Pi no longer hold each other up** (darylc).
- **The Colorlight "no link" warning clears itself** when the link comes up just after boot (darylc).

## System and UI

- **WiFi scans now correctly label WPA3, WEP and Enterprise networks**, and the WiFi status shows the right reason while connecting (darylc).
- **A refused network interface save leaves your saved settings as they were** (darylc).
- **The script editor in the file manager shows and saves scripts exactly as they are** (darylc).
- **A dialog closed while it's still fading in now actually closes** (darylc).
- **Help text clarified:** Command Preset rows that share the same name run together (darylc).
- **Removed `cronjobs.php`,** an unfinished 2014 mockup of a cron editor (darylc).

## Stability fixes

- **Plugins unload more safely.** Network requests still in progress are dropped before plugin libraries are unloaded, avoiding a possible crash on shutdown or reload.

## Raspberry Pi images

- **New Pi images are built on the October 6, 2026 Raspberry Pi OS Trixie Lite release.**

## Upgrade note

- `cronjobs.php` is gone from the web interface; anything linking to it directly will no longer work.
- Recurring Tasks now rejects very short intervals that were previously accepted on Save.
