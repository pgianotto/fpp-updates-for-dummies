# FPP Updates — October 29, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

31 commits, all from Daniel Kulp, mostly LED panel fixes and a broad round of web UI and settings clean-up. One commit landed in the early hours of October 30.

## LED panels

- **Several LED panel setup pages fixed.** The layout drop-downs now fill in correctly when matrix 1 isn't the first one on the page, Front View now flips the orientation icons properly, and a panel size that includes an addressing type keeps it when the page loads.
- The Pi GPIO slowdown default once again follows your Pi model, and the slow network card warning now uses the connection speed it actually detects.
- Change detection now notices a matrix that was saved with a numeric ID, and an empty matrix tab no longer shows a stray note in place of an ID.
- ColorLight panel brightness is now a percentage on every platform (early October 30), and ColorLight start-up warnings clear the next time the configuration is loaded.
- BeagleBone: only the LED triggers your board actually has are offered.

## Scheduler

- A schedule decision now uses the reload you just asked for, so changing the schedule and reloading acts on the new schedule rather than a stale one.

## Settings and security

- Passwords and tokens are no longer included in the settings data sent to web pages.
- The "playlist auto scroll" setting now reaches the status page.
- Settings text boxes that are identified by a CSS class now save their own value and work with custom change handlers.
- The Developer settings branch list starts with nothing selected when your current branch isn't on the remote, instead of picking a wrong one.
- Copying files to or from a remote now includes the cape EEPROM, and the local restore in initial setup points at the real backups folder.

## System and UI

- **Dialogs behave better.** Closing a message box over another dialog no longer removes the backdrop of the dialog underneath.
- Playlist editor notes are shown as plain text.
- The Get Help links wrap properly on a phone.
- The volume display only redraws when the volume actually changes.
- The Virtual Display page loads its scripts once instead of twice.
- Several controls and help icons now have better names for screen readers (footer start/stop button, tooltips, help icon text).
- The notification pop-up setting now loads correctly when set to any value other than 0 or 1.
- The status page title is no longer escaped twice.

## Troubleshooting

- The Display EDID report on the troubleshooting page now works with older versions of `edid-decode`.

## Stability fixes

- Manual updates now rebuild the web security policy using the script's real name, and the security policy no longer drops the quotes around certain keywords and hashes, which could block pages from loading.

## Upgrade note

- If you have scripts or plugins that read the settings data from web pages, passwords and tokens are no longer included there.
- ColorLight brightness is now a percentage on all platforms; re-check any saved brightness values.
