# FPP Updates — October 13, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

Mostly about reliability: timing moved to the monotonic clock, thread-safety fixes, less log spam, and another round of security and MultiSync improvements. Most commits are from Daniel Kulp, with two from OnlineDynamic.

## Timing and thread safety

Nearly all of fppd's timing now uses a clock that doesn't jump, so an NTP correction or manual clock change no longer disrupts it.

- **Covered:** timers and frame cadence; command, If-chain and URL timeouts; the LOR heartbeat and controller pings; video watchdogs, overlay effects and test patterns; uptime.
- **MQTT:** status publishing keeps going after the clock steps back.
- **Shutdown:** stopping fppd is safer.

## Fewer crashes and less log spam

- A config entry of the wrong type is skipped instead of stopping fppd (plugin commands, cape sensors, submodels, processors, `co-universes.json`).
- Running out of network sockets, or a remote sending malformed info, no longer ends fppd.
- Repeated messages are logged occasionally instead of every packet or frame: a taken ArtNet port, unreachable MultiSync remotes, DDP queries, missing sequence names, misfit submodels and slow frames.

## Security

- Descriptions, names and warning text are escaped where pages show them.
- Other websites can no longer read the API unless allowed.
- Reset Config removes links rather than the files they point to.
- A cape can't choose the signing host; restored backups no longer run script install actions.
- Crash reports hide more credentials and the device serial.

## MultiSync and updates

- Remotes that are mid-update show as **Upgrading**, and you can open their live update log.
- A failed remote upgrade, or an unreachable update source, shows as failed.
- Multicast and broadcast sync sends never block (OnlineDynamic).
- The MultiSync page keeps your scroll position.

## Playback and outputs

- **Stop Now always blanks the outputs.**
- Playlist fixes: Stop Now from a PLAYLIST_STOPPED event, MQTT stops vs the scheduler, lead-outs after instant sections, and negative Branch offsets in the editor.
- Sun-relative times use each day's own sunrise or sunset.
- ArtNet says a restart is needed when it fell back to another port; MQTT outputs with wildcard topics and oversized LOR outputs are refused.
- A truncated sequence plays to where its data ends; the persistent media stream is paced by the sound card.
- A non-whole-number volume is refused instead of muting; overlay fills with an RGB color no longer blank the model.

## System and UI

- `fppinit` sets up the network without `/etc/wpa_supplicant` and supports an `FPP_MEDIA_DIR` override; the device leaves AP mode before Wi-Fi starts.
- A restore no longer looks like an OS reflash; Force HDMI sets exactly one option; updates stop adding a line to `/etc/gitconfig` each time.
- New `apply_service_setting` script for background services (OnlineDynamic).
- Crash reports find FPP on their own and say when they couldn't be made.
- Plugins can be loaded from their GitHub URL; banners wrap on phones; streamed jobs finish if the browser disconnects.

## Upgrade note

An external dashboard or page that reads the FPP API directly from a browser may now be blocked unless that site is allowed.
