# FPP Updates — October 24, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

16 commits from Daniel Kulp, darylc and Ben Cole.

## API

- **Browser preflight (CORS) requests to /api are answered**, which allowed sites need to call the API.
- fppd's internal routes are left out of the published API spec.

## Sequences

- FSEQ files can store more than 255 sparse channel ranges (FSEQ 2.3).

## MQTT and scheduler

- An MQTT start stops the running playlist first, and the scheduler no longer interrupts a playlist started over MQTT (darylc).
- Switching playlists isn't treated as a stop by the scheduler (darylc).

## Audio and sync

- Saved input group and routing levels are restored at start.
- A late sync packet no longer makes a remote's audio jump (Ben Cole).

## Outputs and network

- Generic UDP outputs ping their controllers and send multicast on the output interface.
- An output reload can get in even when every cycle runs late.

## Crash reports

- Crash reports tell memory damage apart from a damaged program file.
