# FPP Updates — October 20, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

72 commits, mostly Daniel Kulp with Kyle Grymonprez and OnlineDynamic: tighter MultiSync timing, network outputs that recover on their own, and more security fixes.

## MultiSync timing

- A remote applies its offset to the millisecond; late sync packets no longer pull its lights around.
- A remote's lights go out with the master's, and it adjusts its audio speed to stay in step.
- A video's sound plays through the slot's output, together with its picture.

## Network outputs

- Outputs follow a new IP address, and the invalid-interface warning clears when it appears.
- A socket that failed to open is retried; a controller getting only every other frame raises the pacing warning.

## Automatic retries

- AES67 and Opus streams, video inputs and camera groups that fail to start are retried.

## Security

- MultiSync peers are judged by the addresses they resolve to.
- The web password file and Wi-Fi keys are kept out of the general file APIs.
- A reflash no longer copies a plugin's GitHub token into settings.

## Playlists

- A random playlist resumes on the same entry after a restart, and Start At Item plays what you asked for.
- Random media picks files with mixed-case extensions; a Remap "remove" entry no longer crashes.

## Updates and backups

- An offline rebuild is reported as completed, not failed; backups include both config files of a plugin that has two.

## Hardware and display

- PocketScroller v2's EEPROM is found again.
- A BBShiftPanel PWM panel whose PRU stops answering no longer freezes output.
- Many output warnings clear once the config is fixed; 3D virtual display and sequence-writing fixes (Kyle Grymonprez).

## UI

- Player control pinning is more reliable (OnlineDynamic).
