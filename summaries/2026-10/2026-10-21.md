# FPP Updates — October 21, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

82 commits, the busiest day so far, from Daniel Kulp, darylc, OnlineDynamic and Bryan Brandau: a new October OS image, a security fix that installs without an OS update, and many backup, WLED and setup fixes.

## OS images and security

- A second October OS image (2026-10b) is offered on the About page; Raspberry Pi Imager entry updated to 10.3.
- **The PHP2Shell security fix installs without waiting for an OS update.**
- Interface names, sensor labels and MultiSync remote fields are escaped where pages show them.

## Backups

- File Copy waits for lookups, reselects the saved Remote Storage device, explains unlistable drives, and its drive lock gives up after 30 seconds (darylc).
- Mounting is protected against two backups at once (OnlineDynamic).
- Restoring settings from a backup without presets or proxies keeps this player's own; backups are pruned by when they were taken.

## Outputs

- E1.31/DDP and Pixel Strings Save wait for the save to finish; LED Panels test patterns follow the panel color order (darylc).
- ColorLight never waits on the network card during output and drops whole frames only; remapping is faster.
- Leaving Port Status no longer stops a test it didn't start.

## WLED effects

- Brightness applied once, one-pixel-wide models painted whole, unknown mappings drawn horizontal (darylc); Copy Segment is no longer offered.

## Commands, scripts and playlists

- Slot 0 or an invalid slot no longer runs every unslotted preset; If formulas that don't compile read as not found; hsv() hue wraps (darylc).
- Run Script reports when a script didn't start; paused media reports where it paused (darylc).
- All-digit playlist names validate (Bryan Brandau).
- A passed lunar holiday doesn't rerun this year; Diwali 2034–2035 dates corrected (darylc).

## Setup, media and plugins

- "No Password" in setup is remembered; changes made while setup loads are kept until Finish.
- Set Slot Volume on an idle slot applies at its next start; AES67 instances default to a 1 ms packet time.
- Plugin update checks are no longer lost; File Manager keeps your selection across refreshes.

## Other fixes

- The OLED shows "No Network" promptly and updates once a second on capes with buttons.
- An Experience controller found over HTTP defaults to Bridge mode (darylc).
- Refused API and upgrade requests return proper error codes instead of 200.
