# FPP Updates — October 11–12, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

A very large batch, almost all from Daniel Kulp: a security review of the web UI, a broad crash and race-condition sweep across fppd, and a handful of new features.

## New features and behavior changes

- **LOR Enhanced output:** sends only changed pixels, paced to the line rate; defaults to 1 Mbps; speed hints are labeled for 40fps; the UI keeps the channel count in step with the unit count.
- **Channel output timing:** frames go out on a fixed cadence instead of being timed from each wake-up, for steadier output.
- **Playlist editor:** asks you to save or discard before you leave with unsaved edits; adding a playlist no longer shows "Error loading playlist."
- **NOCC discovery across wireless networks:** new option, off by default (Pat Delaney).
- **Pi 5:** 64-bit images can keep the 16K-page kernel, behind a developer setting.
- **API:** reports each serial device's reboot-stable name.
- **Troubleshooting page:** new Media Files tab that reports each file's codecs, sample rates and sizes, and flags rates that don't match your configured audio rate.
- **HDMI:** an HDMI output starts with no display attached, the display recovers after a TV is unplugged and reconnected (#3102), and framebuffer outputs and video can share a display card.
- **Docs:** state-changing GET API routes are marked for removal in FPP 11.

## Security

- The UI password is hashed with bcrypt on multi-core boards.
- State-changing requests sent by other websites are refused, and action pages no longer allow any site to read them.
- File names and other stored values are escaped where pages show them; scanned Wi-Fi names show as plain text.
- The API no longer returns stored credentials.
- Path tricks are blocked in playlist and sequence names, plugin files, file moves and image saves; scripts only run from the scripts folder.
- Settings that reach root shell commands are validated, and user text can't break out of PipeWire configs.
- Backup restores only restore network interface configs, and the setup wizard's restore only works before setup is done.
- Remote helpers can only reach other players.

## Stability fixes

- **Commands and presets:** malformed commands or a malformed `commandPresets.json` no longer crash fppd; reloading presets no longer deadlocks; quotes in values no longer break If commands or routing presets.
- **Overlays and WLED effects:** several buffer overruns fixed (including long Scrolling Text); WLED effects on multiple models no longer share one strip's state.
- **Playlists:** a Restart/Next/Prev Playlist Item entry no longer crashes; a repeating playlist of instant entries no longer spins; paused media resumes correctly; a playlist started part-way in repeats in full; random media only picks media files.
- **Scheduler:** past-midnight and sun-relative times are right on DST change days; Easter-relative holidays and odd/even days use calendar dates; schedules re-arm after the clock steps back; a warning appears when a lunar holiday has no date for the year.
- **MultiSync:** a remote's fallback sequence follows the master; remotes only play sync files inside their media folders; batch actions on the MultiSync page no longer freeze other tabs, and a failed action offers Retry and Close Log.
- **Audio, video and AES67:** PTP keeps retrying after a failed start; failed pipelines rebuild with a backoff; video inputs and outputs restart after failures; boot audio setup handles card 10 and up; media warnings clear once fixed.

## Outputs and hardware (October 11)

- BeagleBone PRU outputs: fixes across 48String, BBShiftPanel and BBBMatrix, including 1/20-scan panels and 6- and 7-bit color depth.
- Fixes for FalconV5, panel interleaves, and channel limits on PCA9685, MCP23017 and PCF8574.
- Serial outputs send whole frames, the DMX break comes after the last frame, and a Renard output too fast for its speed is refused.
- E1.31 sync goes out the right interface; multicast and broadcast stay on the output interface; Twinkly logs back in as soon as the device answers.
- Virtual display fixes; RGBW pixels with white off now show; W-first color orders map correctly.
- Many output config warnings clear when the config is reloaded.

## Upgrade note

Check custom scripts or integrations that use GET requests to change state, read credentials from the API, or call FPP from another web page; the new checks may affect them.
