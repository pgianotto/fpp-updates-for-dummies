# FPP Updates — October 30, 2026

*Unofficial, AI-written summary of the day's commits to FPP master. See the [commit log](https://github.com/FalconChristmas/fpp/commits/master) for the details.*

26 commits from Daniel Kulp, Daryl C. (darylc) and Pat Delaney, mostly HDMI display settings, File Manager polish and a round of small fixes. Three commits from Pat Delaney are from October 27–28 and only landed on master yesterday.

## Video and HDMI

- **Clearer help when a display's shape doesn't match its resolution.** FPP now tells you which resolution to set, and camera and stream groups on HDMI get the same banner.
- The HDMI display settings now show up in both Media Backend modes.
- A display that refuses video now gets its own warning instead of a generic one.
- The Force HDMI Resolution list no longer repeats modes, and 2560x720 now correctly shows 120 Hz instead of 12. A Compute Module 4 now gets the same HDMI modes as a Pi 4.
- Settings groups with nothing to show on your board no longer print an empty heading.

## Playlists and File Manager

- **New "Don't automatch" option in Bulk Add** (Pat Delaney). When bulk-adding items to a playlist you can tick a box to skip automatic matching; the pop-up message now says "Automatch Enabled/Disabled" like other settings.
- Tail Follow in the log viewer now sends whole lines instead of cutting them mid-way.
- A filtered file list now says "Filtered items" and counts only what you can see, and unticking Filter clears the filter and hides its boxes.

## Plugins

- Plugin uninstall scripts are now told when they are only the first half of a Reinstall, so they can keep your settings (Daryl C.).
- Plugin scripts now run on macOS (Daryl C.).

## Outputs and hardware

- Pi PWM outputs now drive the right PWM channel on their pin, and the log no longer says a pin doesn't support PWM when it does.
- The OLED display tool no longer doubles its GPIO label ("FPPOLED-Back", not "FPPOLED-FPPOLED-Back").

## Stability fixes

- An upgrade step (102) no longer stops upgrades from older versions in their tracks.
- The health check's text report now labels a warning "Warning" instead of "Pass".

## System and UI

- The volume slider now sends the value where you let go.
- The SSH Shell link keeps working when you reach FPP on a non-standard port.
- A unicast address made only of digits and dots is now treated as an IPv4 address.
- Behind the scenes: Docker setup and no-cache builds were fixed.

## Upgrade note

- Plugin authors: `fpp_uninstall.sh` is now told when it runs as part of a Reinstall, so scripts that wipe settings on uninstall may want to check for that.
